# C++ Console Calculator and GUI Evolution Project

A professional, version-controlled calculator project developed as part of a Computer Engineering portfolio. This project showcases the transition from a modular, console-based system to a full-featured Graphical User Interface (GUI) and the architectural evolution of custom calculation logic.

## 🚀 Project Roadmap and Versioning
* **v1.0 (Console Base):** Initial version featuring basic console-based calculation logic, structural modularity, and a menu system. *(Completed)*
* **v1.1 (Logic Enhancement):** Implementation of advanced grouping rules, sequential operation logic handling multiple numbers, and an improved menu flow. *(In Progress)*
* **v2.0 (GUI Transition):** Migration of the core logic to a modern desktop Graphical User Interface. *(Planned)*

## 🛠️ Features
* Modular C++ architecture separating calculation logic from user interaction.
* Custom sequential operations (handling of multi-number groupings).
* Clean, documented, and version-controlled Git history reflecting professional development practices.

## 💻 Getting Started (Console Version)
Clone the repository and compile the source code using any standard C++ compiler (such as g++). You are welcome to contribute to the project and add new features, provided they do not disrupt the core codebase structure. :)
